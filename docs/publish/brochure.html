OS Monitor · Linux 노드 모니터링

클러스터 아래 운영체제까지, 한 화면에서

Kubernetes 노드의 Linux 상태를 모으고, 이상을 먼저 알리고, 자원이 바닥나기 전에 알려 줍니다. 이미 쓰고 있는 Prometheus와 Loki 위에 그대로 올라갑니다.

왜 필요한가

파드가 멀쩡해 보여도 노드는 지치고 있을 수 있습니다

디스크가 차오르거나, 메모리가 바닥나 OOM Kill이 일어나거나, 커널 오류가 쌓이는 문제는 Kubernetes 화면에서 잘 보이지 않습니다. OS Monitor는 그 아래층을 봅니다.

60초

바로 알아차립니다

노드 8대의 CPU·메모리·디스크·부하를 1분마다 확인하고, 기준을 넘으면 이벤트로 남깁니다.

9가지

원인까지 짚습니다

시스템 로그에서 OOM Kill, 디스크 I/O 오류, 커널 패닉 같은 이상 징후 9가지를 자동으로 찾아 이벤트 옆에 붙입니다.

90일

미리 대비합니다

최근 30일 추세로 7·30·90일 뒤 사용률과 자원이 가득 찰 때까지 남은 날을 계산하고, 신뢰도를 함께 보여 줍니다.

핵심 기능

수집부터 보고까지 한 제품으로

COLLECT

OS 지표 수집

CPU, 메모리, 스왑, 디스크, inode, 네트워크, 부하, 코어 수, 가동 시간, 실행 중·좀비 프로세스까지 수집합니다.

LOGS

시스템 로그 분석

각 노드의 systemd journal을 우선순위·서비스·노드별로 걸러 보고, 이상 징후를 노드별 건수로 보여 줍니다.

DETECT

위기 감지와 진단

임계값을 넘으면 같은 시간대 로그와 함께 원인, 해결 방법, 공식 문서 링크를 제시합니다.

PREDICT

용량 예측

선형 회귀와 이상치 제거로 추세를 계산하고, 7일 안에 가득 찰 자원은 긴급 권고로 올립니다.

REPORT

정기 리포트

일간·주간·월간·연간 리포트를 HTML·PDF·JSON으로 만듭니다. 일간 리포트는 매일 새벽에 자동으로 만들어집니다.

ACCESS

대시보드 · CLI · API

웹 대시보드와 터미널 CLI, REST API를 제공합니다. 계정별로 볼 수 있는 화면을 정할 수 있습니다.

작동 방식

데이터는 이렇게 흐릅니다

모으기

이미 운영 중인 Node Exporter와 Loki에서 지표와 로그를 가져옵니다.

쌓기

TimescaleDB에 시계열로 저장하고, 시간 단위 집계를 자동으로 유지합니다.

판단하기

임계값 검사, 로그 징후 탐지, 추세 예측을 실행합니다.

보여 주기

대시보드, CLI, 리포트, API로 결과를 전달합니다.

있는 것을 다시 씁니다

노드에 새 DaemonSet이나 에이전트를 깔지 않습니다. 이미 수집하고 있는 Prometheus·Loki 데이터를 읽기만 합니다.

노드 키를 나눠 주지 않습니다

SSH 접속 없이 모든 항목을 지표로 수집합니다. 관리할 계정과 키가 늘지 않습니다.

Git이 곧 배포입니다

이미지 태그를 커밋하면 ArgoCD가 자동으로 맞춥니다. 비밀값은 Sealed Secrets로 암호화해서 함께 보관합니다.

숫자에 신뢰도를 붙입니다

예측은 데이터 양에 따라 high·medium·low·very_low로 표시해서, 근거가 얕은 숫자를 과신하지 않게 합니다.

사양

기술 사양

모니터링 대상Kubernetes 클러스터 노드의 Linux OS (Kubernetes 리소스 자체는 제외)
데이터 소스Prometheus + Node Exporter (PromQL), Loki + systemd journal (LogQL)
수집 주기60초 · 예측 매일 02:30 · 일간 리포트 매일 01:00
저장소TimescaleDB (hypertable, 시간 단위 연속 집계)
서버Python 3.11, FastAPI, asyncpg, 속도 제한, OpenAPI 문서
화면정적 웹 대시보드(라이트/다크), Rich 기반 CLI
인증아이디·비밀번호 로그인(PBKDF2), 세션 토큰, 관리자·조회자 역할과 화면별 권한
배포컨테이너 이미지 3종, Kustomize, ArgoCD 자동 동기화, Sealed Secrets
도입

도입 절차

  1. 클러스터에 Prometheus(Node Exporter)와 Loki가 있는지 확인합니다.
  2. 노드 저널 수집기(promtail)를 배포하고, 노드에 영구 저널을 켭니다.
  3. Sealed Secrets로 DB 비밀값을 봉인하고, ArgoCD Application을 등록합니다.
  4. 대시보드에 접속해 기본 관리자 비밀번호를 바꾸고 사용자 계정을 만듭니다.

필요한 환경

  • Kubernetes (1.34에서 운영 중), Gateway API 또는 NodePort
  • kube-prometheus-stack (좀비 지표에는 --collector.processes)
  • Loki, ArgoCD, 사내 컨테이너 레지스트리
  • TimescaleDB용 영구 볼륨
